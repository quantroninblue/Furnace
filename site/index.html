The AI coding workspace where you stay in charge.

Talk an idea through, research it, turn it into a plan, and let the agent build it: reading code, editing files and running commands, while you decide how much it may do on its own. Built on Code OSS, so the editor, terminals, Git and debugger you know are all there.

What makes Furnace different

Every model, every change on record, and the agent only does what you allow.

One conversation, every model

Use your ChatGPT plan, Claude Code, an OpenAI or Anthropic key, or local models through Ollama. Switch mid-conversation: the chat, your plan, sources and shared context come along.

Autocompute: local models do the small jobs

Your online model leads and hands unit tests, small edits, renames and docs to the models on your machine, then reviews their work. Furnace learns what each local model is good at.

Jump between versions from the chat

Every reply that changes files is a checkpoint. Open the Timeline to compare with any earlier message, revert one file or a whole reply, or rewind and edit what you asked.

Plans that prove themselves

Each step carries a check. The agent ticks a step off only when its check passes, and keeps the output as proof.

- [x] Parse ISO dates (check: `npm test -- dates`)

A second opinion before you keep anything

Ask another model to review the agent's changes for bugs and missed requirements, then send its notes back with Fix These.

You set the limits

Approve every change, let everyday work run in a sandbox, or give full access for trusted tasks. Once web content enters the chat, Furnace asks before every command.

Research with sources

Browse in a separate, private research window and capture what matters. Answers cite their sources, all the way into your plan and code comments.

Work in parallel

Hand a task to a background agent that works in its own copy of your project while you keep coding, then review and apply its changes.

Make it yours

Privacy

Your data stays yours.

Furnace runs entirely on your computer. We never receive your prompts, files, keys or sign-ins. Read exactly what is sent and stored.

  • No Furnace account, server or telemetryThere is nothing to sign up for and nothing reporting back to us.
  • Only what you send leaves your computerAnd only to the model you chose. Context chips show exactly what the agent sees.
  • Your accounts, your billingFurnace never switches accounts or falls back to paid billing on its own, and API replies show what they cost.
  • Fully local when you want itWith a local Ollama model, nothing leaves your machine at all.

Get going

From download to your first change in a few minutes.

A short tutorial walks you around the window the first time you open Furnace.

  1. Connect a model

    Sign in with ChatGPT, use your installed Claude Code, add an API key, or pick a local Ollama model.

  2. Open a project

    Open a folder and choose Trust Folder so the agent can work on its files.

  3. Describe the task

    Discuss to talk it through, Plan to draft a plan, Build to do the work, Research to work from sources.

Download

Get Furnace.

Free and open source under the MIT license. Furnace tells you when a new version is out and installs it for you.

macOS Apple Silicon · macOS 13 or later

Download for macOS
  1. Open the disk image and drag Furnace to Applications.
  2. Open Furnace. macOS can't verify it yet, so choose Done.
  3. In System Settings → Privacy & Security, choose Open Anyway.

Furnace-darwin-arm64.dmg

Windows 64-bit Windows 10 or 11

Download for Windows
  1. Run the installer. It installs for your user, no admin rights needed.
  2. If SmartScreen appears, choose More info, then Run anyway.
  3. Optional: install Git for Windows so the agent can use Git Bash.

FurnaceUserSetup-x64.exe

Linux 64-bit · Ubuntu 24.04+, Debian 13+, Fedora 40+

Download .deb Download .rpm
  1. Ubuntu, Debian, Mint: sudo apt install ./Furnace-linux-x64.deb
  2. Fedora: sudo dnf install ./Furnace-linux-x64.rpm
  3. Open Furnace from your apps, or run furnace.
