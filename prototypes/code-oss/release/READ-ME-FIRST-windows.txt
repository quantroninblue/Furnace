Furnace test build for Windows (64-bit Windows 10 or 11)

Install
1. Run FurnaceUserSetup-x64.exe. It installs for your user only and does not
   need administrator rights.
2. Windows SmartScreen says "Windows protected your PC", because this test
   build is not code-signed. Click More info, then Run anyway.
3. Recommended: install Git for Windows (https://git-scm.com/download/win).
   The agent then runs commands in Git Bash; without it, it uses PowerShell.
   Claude Code on Windows needs Git for Windows too.

Use
- Bring your own model: sign in with ChatGPT (Plus or Pro), use the Claude
  Code CLI, add an API key, or run Ollama locally. Furnace has no account or
  server of its own and sends nothing to us.
- There is no command sandbox on Windows yet, so in Auto mode the agent asks
  before every command. Edits inside the project still apply directly.
- Open a project folder and trust it, then give the agent a small task.

Feedback
- Type /diagnostics in the chat to copy a report (no keys or conversations)
  and send it with a note about what you tried and what happened.
