# Review, revert or rewind

- Each reply lists the files it changed: **Review** opens the diffs, **Revert** undoes one file or the whole reply.
- In the editor, every block the agent changed has **Keep** and **Revert** above it.
- **Second Opinion** asks another model to review the changes; **Fix These** sends its notes back.
- The **Timeline** (clock icon in the conversation) jumps to any earlier message, compares the files with now, or rewinds to it.
- Select code and press **Ctrl+Alt+E** for an inline edit; **Ctrl+Enter** accepts, **Escape** rejects.
