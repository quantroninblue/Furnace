# Connect a model

| Connection | Billing |
| --- | --- |
| **ChatGPT** | Your ChatGPT plan, signed in with your account |
| **Claude Code** | The account of your installed Claude Code CLI |
| **API keys** (OpenAI, Anthropic) | Provider API billing; AI GUI shows the estimated cost of each reply |
| **Ollama** | Free and local: nothing leaves this machine |

Choose the model for each mode in the conversation's **Active model** picker. AI GUI never falls back to another account or to paid billing on its own.
