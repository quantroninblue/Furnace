# Run a first task

1. Choose the **Build** page in the Workspace view (or press Alt+3 in the conversation).
2. Describe a small change, for example: *Create hello.txt that says hello, then list the files.*
3. Watch the steps. Approve or deny anything that asks.

Plan first for larger work: the **Plan** page holds a checklist, each step can carry a check (``(check: `npm test`)``) that proves it before it is ticked. Long tasks can run in the background in their own Git worktree (`/background`).
