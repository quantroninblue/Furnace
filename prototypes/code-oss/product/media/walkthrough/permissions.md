# Permissions

- **Ask first**: every file change, command and web fetch waits for your approval.
- **Auto**: edits inside the project apply directly; commands run in a sandbox (project and temp folders only, no network). Anything else asks.
- **Full access**: no approvals and no sandbox. Use it only for tasks you supervise.

If a chat contains untrusted content (web pages, research sources, files from outside the project), commands and web access always ask, even with full access.
